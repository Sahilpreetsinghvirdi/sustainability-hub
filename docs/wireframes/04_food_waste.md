## Error States

| Error | UI | Recovery |
|-------|----|----------|
| Camera fails | "Could not access camera. Check permissions." | Retry / Gallery fallback |
| AI can't identify food | "Point camera closer to the food" + manual entry | User adds items manually |
| Photo too blurry | "Image unclear. Retake or enter manually" | Retry / Manual |
| Storage full | "Free up space to save meal photos" | Clear old cache |
| Streak broken | Gentle "Streak reset. Start fresh today!" with encouragement | None (by design) |

## Accessibility

- **Screen Reader**: Full alt text for detected foods, "Chicken breast, 180 grams, 92% confidence"
- **Haptic Feedback**: Success pulse on zero-waste log
- **Dynamic Type**: All text scales
- **High Contrast**: Waste categories use patterns + icons, not just color
- **Voice Control**: "Tap Camera", "Tap Dinner", "Tap Save"
- **Motor Assist**: Larger capture button, auto-capture option
